# Datacora - Desarrollo backend SQL Server

Fecha de inicio: 2026-07-21

Esta carpeta es una copia de la version estable Supabase y se usara para construir la variante con backend propio y SQL Server.

Objetivo inicial:
- Mantener la version Supabase intacta.
- Crear un backend intermedio para reemplazar gradualmente Supabase.
- Migrar autenticacion, tareas, formularios, respuestas, fotografias y reportes hacia SQL Server.
- Conservar compatibilidad funcional con la APK actual mientras se avanza por etapas.

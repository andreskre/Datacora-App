# Datacora - Version estable Supabase

Fecha de corte: 2026-07-21

Esta version queda como base estable conectada a Supabase.

Incluye:
- Formularios operativos para tecnico.
- Guardado offline y sincronizacion con Supabase.
- Resumen de bitacora para jefatura.
- Respaldo automatico de PDF y fotografias.
- Envio automatico de correo con PDF.
- Seleccion opcional de articulos instalados por elemento, con cantidad por articulo.
- Seccion independiente de articulos utilizados eliminada del flujo.

La carpeta `Datacora_SQLSERVER_DEV` se usara como base para la nueva version con backend y SQL Server.

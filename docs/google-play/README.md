# Publicacion Google Play - Datacora

Esta carpeta contiene la documentacion base para preparar la publicacion de Datacora en Google Play.

## Documentos incluidos

- `ficha-play-store.md`: textos sugeridos para la ficha de Google Play.
- `politica-privacidad-borrador.md`: borrador de politica de privacidad para publicar en una URL publica.
- `matriz-data-safety.md`: matriz para completar la seccion "Data safety" de Play Console.
- `usuarios-demo.md`: cuentas sugeridas para revision de Google.
- `checklist-tecnico-release.md`: pasos tecnicos antes de subir el App Bundle.
- `capturas-y-assets.md`: lista de imagenes y capturas necesarias.

## Pendientes antes de publicar

- Definir URL publica de politica de privacidad.
- Confirmar correo de soporte visible para Google Play.
- Confirmar paquete final Android, por ejemplo `cl.soser.datacora`.
- Generar version release firmada en formato `.aab`.
- Crear usuarios demo reales en la base productiva o ambiente de revision.
- Validar backend productivo por HTTPS.
- Revisar que la declaracion de datos en Play Console coincida con la politica de privacidad.

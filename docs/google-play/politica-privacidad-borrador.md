# Politica de privacidad - Datacora

Fecha de ultima actualizacion: pendiente.

Datacora es una aplicacion interna de SOSER destinada a digitalizar procesos de mantenimiento, bitacoras, tareas, incidencias y registros en terreno.

SOC DE SERVICIOS DE ALIMENTACION S.A.

## Datos que puede recopilar la aplicacion

Datacora puede recopilar y procesar los siguientes datos, segun el perfil del usuario y las acciones realizadas:

- Datos de cuenta: nombre, correo electronico, RUT, perfil, cargo, zona, grupo y estado de usuario.
- Datos operativos: tareas asignadas, RBD, establecimiento, zona, tipo de visita, prioridad, estado y fechas de planificacion.
- Formularios: respuestas ingresadas, observaciones, articulos utilizados, cantidades, firmas y registros asociados a bitacoras.
- Fotografias: imagenes capturadas como evidencia de mantenimiento o incidencias.
- Ubicacion: latitud y longitud al iniciar y finalizar formularios, junto con datos de distancia respecto del establecimiento cuando corresponda.
- Notificaciones: token de dispositivo para enviar avisos relacionados con tareas, incidencias y mensajes internos.
- Uso de la cuenta: ultima conexion registrada para fines de control operativo y soporte.

## Finalidad del uso de datos

Los datos se utilizan para:

- Registrar y respaldar visitas de mantenimiento.
- Coordinar tareas entre tecnicos, jefes de mantenimiento y administradores.
- Notificar nuevas asignaciones, incidencias y mensajes internos.
- Generar respaldos PDF y reportes operativos.
- Validar la ejecucion de trabajos en establecimientos.
- Dar continuidad operacional cuando exista baja conectividad.
- Mejorar trazabilidad, soporte y control interno.

## Permisos del dispositivo

La aplicacion puede solicitar permisos para:

- Camara: capturar fotografias de evidencia.
- Ubicacion: registrar ubicacion de inicio y termino de formularios.
- Notificaciones: informar tareas, incidencias, respuestas y mensajes internos.
- Internet: sincronizar informacion con el backend de Datacora.
- Almacenamiento interno: guardar temporalmente respuestas y fotografias pendientes de sincronizacion.

## Conservacion de datos

Los datos se conservan durante el tiempo necesario para cumplir fines operativos, contractuales, auditoria interna y respaldo documental de los procesos de mantenimiento.

## Comparticion de datos

Datacora no esta orientada a la venta de datos personales. La informacion puede ser procesada por servicios tecnologicos necesarios para la operacion de la plataforma, como servidores, almacenamiento, correo electronico, notificaciones y base de datos.

## Seguridad

La aplicacion utiliza autenticacion de usuarios autorizados, comunicacion con backend controlado y permisos por perfil. El acceso a la informacion depende del rol asignado a cada usuario.

## Derechos de los usuarios

Los usuarios pueden solicitar revision, correccion o eliminacion de informacion personal segun corresponda a las politicas internas de SOSER y la normativa aplicable.

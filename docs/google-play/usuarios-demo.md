# Usuarios demo para revision de Google

Google Play puede solicitar credenciales para revisar aplicaciones con login. Estas cuentas deben existir en el ambiente que se entregue para revision.

## Cuentas sugeridas

| Perfil | Correo sugerido | Clave sugerida | Proposito |
| --- | --- | --- | --- |
| Tecnico | tecnico.demo@soser.cl | Definir clave temporal | Ver tareas, completar formulario, tomar fotografia y sincronizar |
| Jefe de Mantenimiento | jm.demo@soser.cl | Definir clave temporal | Ver zona, tecnicos, tareas, incidencias, mensajes y bitacoras |
| Administrador | admin.demo@soser.cl | Definir clave temporal | Ver gestion de usuarios, tareas y mensajes |
| Prevencionista | prevencion.demo@soser.cl | Definir clave temporal | Levantar incidencias con fotografias |

## Recomendaciones

- Usar datos ficticios o controlados.
- Crear al menos un RBD demo con coordenadas.
- Crear una tarea pendiente para el tecnico demo.
- Crear una incidencia demo para que el JM pueda revisarla.
- Evitar credenciales reales de produccion en Play Console.
- Cambiar o revocar claves demo despues de la revision si se usan en ambiente productivo.

## Texto para Play Console

La aplicacion requiere inicio de sesion. Utilice las siguientes credenciales demo para revisar las funciones principales:

- Usuario tecnico: pendiente.
- Usuario JM: pendiente.
- Usuario administrador: pendiente.
- Usuario prevencionista: pendiente.

El ambiente de revision contiene datos de prueba y establecimientos ficticios/controlados.
